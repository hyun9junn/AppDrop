AI PACKAGING PIPELINE
Input: 7 form answers
→ LLM generates: description, tagline, use cases, social copy
→ Template engine renders: Story card
→ Tags auto-generated + editable
→ Embeddings created for delivery matching
AI DELIVERY ENGINE
Input: user's plain-language problem
→ LLM interprets intent + extracts key needs
→ Semantic search against app embeddings
→ Re-rank by boost signals + recency
→ Return top 3–5 as Story cards
GROWTH & LOYALTY
Boost: stored per-user per-app
→ Affects delivery ranking weight

Follow: user ↔ creator subscription
→ New app drop triggers notification

Shareable Story card link → deep links into delivery result
